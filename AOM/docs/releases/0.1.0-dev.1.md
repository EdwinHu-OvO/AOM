# AOM 0.1.0-dev.1

## Status

First local dev build release.

This is not a public npm/crates.io release. It is a reproducible local build package for the
current AOM PoC baseline, intended for Agent/MCP integration demos and follow-up development.

## Scope

This dev build closes the current baseline across:

- Phase 2 Analysis graph, Evidence, MVP data-flow graph, and context pack.
- Phase 3 executable capability MVP and effect verification.
- Phase 5 Agent Interaction Layer through `@aom/agent-mcp`.
- Console audit baseline through `@aom/console`.
- Context window routing, semantic `contextDelta`, compact tool responses, and dynamic
  `aom.call_chain` orchestration.

The build intentionally does not claim:

- a complete Safety Gateway;
- general native OS hook/runtime coverage;
- public package registry compatibility;
- complete app-wide data lineage for arbitrary apps.

## Build Command

From `AOM/`:

```bash
pnpm release:dev 0.1.0-dev.1
```

The command writes local artifacts to:

```text
AOM/releases/0.1.0-dev.1/
```

Generated files include:

- `aom-0.1.0-dev.1-workspace.tar.gz`: source + generated TypeScript `dist/`, excluding
  `node_modules`, Rust `target`, logs, and release outputs.
- package tarballs for `@aom/protocol`, `@aom/electron-probe`, `@aom/agent-mcp`, and
  `@aom/console`.
- `manifest.json` with git/build metadata.
- `SHA256SUMS` for artifact verification.

`AOM/releases/` is ignored by git; release notes and build scripts are the committed source of
truth.

## Required Validation

Before treating this dev build as usable, run:

```bash
cd AOM && cargo test
cd AOM && pnpm test
cd AOM && pnpm build
cd targetAPP && pnpm test
cd targetAPP && pnpm build
git diff --check
```

## Handoff Notes

- Restart the AOM MCP server after installing this build so tool schemas include
  `aom.context_delta` and `aom.call_chain`.
- Treat `aom.call_chain` as an orchestration suggestion, not an executor. All lower-level AOM
  tools remain available for debugging and fallback.
- The next development focus should move from Analysis Core expansion to default runtime coverage:
  OS-level fallback probes and user-approved runtime attachment.
